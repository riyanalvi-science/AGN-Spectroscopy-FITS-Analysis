# AGN Spectroscopy FITS Analysis 

## Computational Analysis of Optical Spectroscopic Data of Active Galactic Nuclei using FITS files.

This project focuses on computational analysis of optical spectroscopic data of Active Galactic Nuclei (AGN) using astronomical FITS files.

## Project Overview 

The project involves:

- Understanding astronomical spectroscopy
- Processing FITS data
- Extracting spectral information 
- Performing wavelength calibration
- Visualizing optical spectra
- Comparing spectra from different observations 

## Objects Studied

- PKS 0454-234
- PKS 0502+049

## Tools used

- Python
- Astropy
- NumPy
- Matplotlib
- Pandas
